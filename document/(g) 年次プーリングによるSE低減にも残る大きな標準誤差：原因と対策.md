# 年次プーリングによるSE低減にも残る大きな標準誤差：原因と対策

年別の推定値をプールしても標準誤差が依然として大きいのは、食品群ごとの消費量のばらつき（標準偏差）が非常に大きく、サンプルサイズの平方根で割ってもなおSEが高止まりしているためです。以下の構造的要因と具体的な対策を検討してください。

## 1. 標準誤差が大きい要因

-   **極端なばらつき（大きな標準偏差）** 食品群の消費量は一部世帯で極端に高い値をとるため、全体のSDが肥大化。
-   **サンプルサイズの限界** 各地域×所得階層ごとのセルにおけるnは増やせても、SDが数万から十数万と極めて大きいため、$\text{SE}=\sigma/\sqrt{n}$で計算してもSEは大きいまま。
-   **アウトライヤー除去の限界** IQRベースの外れ値カットでも、分布の裾（heavy tails）を完全には排除しきれず、SDへの影響が残る。

## 2. ばらつき抑制のためのデータ変換・要約量

1.  **対数変換・平方根変換**
    -   消費量を $\log(x+1)$ や $\sqrt{x}$ に変換することで正の歪度や裾野を圧縮し、分散を小さくする。
2.  **トリミング平均・メジアン**
    -   上位数パーセンタイルを切り捨てるトリム平均や、メジアン（中央値）を代表値として用いることで、外れ値の影響を大幅に低減。
3.  **四分位範囲（IQR）での中心化**
    -   各セル内で $[Q_1-1.5\times IQR,\;Q_3+1.5\times IQR]$ 以外の値を欠損扱いにし、さらに極端値を除去。

## 3. モデルベースの推定で「借り入れ」

-   **階層ベイズモデル／混合効果モデル** 各年×地域×所得層をランダム効果に設定し、全体の分散構造から“借り入れ”を行うことで、セル内推定のSEを効率化。
-   **スムージング・時系列モデル** 年次トレンドを局所的回帰（LOESS）や構造時系列モデルで平滑化し、年間のノイズを抑制。
-   **多変量回帰で共変量調整** 食品価格指数やインフレ率、季節要因などを共変量に入れ、残差のばらつきを削減。

## 4. セルの再集約によるサンプルサイズ増加

-   **地域区分の統合** 隣接する地域をまとめてサンプルを増やし、標本サイズをさらに拡大。
-   **所得階層の粗分類** 例えば5層→3層にするなど、階層数を減らして各セルのnを倍増。

## 5. 感度分析と結果の頑健性確認

1.  **元の年別分析 vs. プーリング＋調整モデル**
    -   両者の推定値・SEを比較し、バイアスの有無とSE抑制効果を評価。
2.  **データ変換の前後比較**
    -   消費量の対数化やトリム後の推定値・SEを年別・プール別それぞれで確認し、変換がどれほどSEを低減したか検証。
3.  **クロスバリデーション**
    -   セル単位でデータを分割し、予測誤差と信頼区間幅を比較してモデルの汎化性能を確認。

------------------------------------------------------------------------

**まとめ** プーリングによる単純なサンプルサイズ増加だけでは、極端なばらつきを抑えきれずSEが高止まりする。対数変換やトリム平均、階層モデルなどの手法で分散構造を改善し、モデルベース推定で情報の「借り入れ」を行うことで、標準誤差を効果的に低減しつつ年次トレンドを捉えることが可能となる。 [^年次プーリングによるse低減にも残る大きな標準誤差：原因と対策-1]
