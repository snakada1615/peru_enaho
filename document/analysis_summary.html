ペルーの食品消費データ分析：処理ワークフロー

ENAHO調査データの加工から検証まで

Research Team

2025-11-10

スライド1：分析の全体像

目的 - ペルー全国世帯調査（ENAHO）の食品消費データを分析 - 栄養介入プログラム（CRECER, JUNTOS）の影響評価

対象データ - 年間データ: 2007～2016年（10年間） - 調査対象: 世帯ごとの食品群別消費量 - 重層化複雑標本設計を反映した分析

主な処理段階 1. データ準備・加工 2. 検証・品質管理 3. 基本統計分析

スライド2：第1部 データ準備（file1.txt）

ステップ1：世帯構成員の算出（関数 get_familysize_ame） - 年齢計算: 誕生月年から現在の年月で計算 - 成人男性換算（AME）: 性別・年齢グループ別の係数を適用 - 出力: 世帯の家族人数とAME換算値

ステップ2：食品群別消費量の集計（関数 get_food_consumption_family） - 調査記録から消費単位・頻度を読み込む - グラム換算係数を適用 - 食品分類に基づいて8つの食品群に集計

スライド3：第1部 データ準備（続き）

ステップ3：1人当たり消費量への変換（関数 get_food_consumption_capita） - 家族単位の消費量をAMEで除算 - 1人1日あたりの食品群別消費量を算出

ステップ4：地域・所得情報の付与 - 地域分類: 海岸（Costa）/ 山岳（Sierra）/ アマゾン（Selva） - 県別コード・都市/農村区分 - 介入状況: 2009年・2011年の開始タイミング別に分類

ステップ5：対数変換とスコア算出 - log1p変換: ゼロ値対応 - 推奨摂取量に基づくスコア: 最適値（1）/ 超過（2）/ 不足（3）

スライド4：第1部 全体処理フロー

年次ループ（2007-2016）
│
├─ mod1（基本情報）, mod4（世帯構成）読み込み
├─ mod5（JUNTOS情報）, mod7（食品消費）読み込み
│
├─ 家族人数・AME計算
│  └─ 成人男性換算係数を適用
│
├─ 食品消費量の集計
│  └─ 家族単位 → 1人当たり消費量
│
├─ 地域・経済情報の統合
│  ├─ 地域・県・介入状況の付与
│  └─ 所得・JUNTOS参加情報の統合
│
└─ 最終処理
   ├─ 対数変換
   ├─ スコア算出
   └─ 年次統合データとして保存

スライド5：第2部 データ検証（file2.txt）

処理1：svydesign の設定 - 複雑標本設計を反映: PSU（コングロメラット）、層（ESTRATO）、重み（FACTOR07） - 所得5分位の計算: 加重分位数を用いたグループ化

処理2：外れ値除去（関数 detect_outliers_weighted × 2回実施） - 重み付きIQR法による外れ値検出 - グループ別（地域×所得または都市/農村×所得）の柔軟な外れ値判定 - 検出結果の記録: 外れ値数・割合を統計化

スライド6：第2部 データ検証（続き）

処理3：スコアの再計算 - 外れ値除去後のデータセットで食品スコアを再計算 - 2パターンの外れ値処理結果を保存 - パターン1: 地域（region）× 所得5分位 - パターン2: 都市/農村（area）× 所得5分位

処理4：基本統計の確認 - gtsummary/gtパッケージを用いた記述統計 - グループ別（処理群/対照群、処理年等）の比較 - セル毎の平均値と標準誤差を計算

スライド7：第2部 品質管理プロセス

データ検証パイプライン
│
├─ svydesign 作成
│  └─ 複雑標本設計を反映
│
├─ 外れ値検出・除去（第1回）
│  ├─ 地域 × 所得5分位でグループ化
│  ├─ 重み付きIQRで外れ値判定
│  └─ スコア再計算
│
├─ 外れ値検出・除去（第2回）
│  ├─ 都市/農村 × 所得5分位でグループ化
│  ├─ より細かい地理区分で検証
│  └─ スコア再計算
│
└─ 基本統計の確認
   ├─ 記述統計表の作成
   ├─ グループ別比較
   └─ クリーンデータの保存

スライド10：次のステップと留意点

分析に向けた準備 - クリーンデータ（clean2）を使用 - 複雑標本設計を反映した統計検定（survey パッケージ） - グループ間の平均値差検定にはsvydesign設計を活用

主要な分析方法 - 記述統計: svyby による層別集計 - 因果推論: Difference-in-Differences（処理前後×処理群/対照群） - 回帰分析: 複雑標本設計対応の加重ロジスティック回帰

データ品質の確保 - 外れ値除去の妥当性確認 - グループ別のサンプルサイズ確認 - 欠損値パターンの把握
