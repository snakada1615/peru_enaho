# セル平均だけでは失われる分散情報とその対策

地域区分×年次×所得区分ごとに算出した**食品群の平均消費量**を他データにマージすると、セル内における世帯間のばらつき情報が消失し、モデル解釈に問題が生じるリスクがあります。以下では、ばらつき情報を保持する方法とモデルへの組み込み方を解説します。

------------------------------------------------------------------------

## 1. 平均だけのマージで失われる情報

-   **個別世帯差の不在** 各セルごとのばらつき（標準偏差や分位数）が反映されず、すべての世帯に「同じ値」が割り当てられることで、ばらつきの効果（例：異なる消費パターンの説明力）がモデル外に置き去りにされる。
-   **推定バイアスの可能性** 世帯間の相関構造（例：消費量の高い世帯が他の特性でも異なる）が平均に反映されず、交絡や誤差項の構造を歪める可能性。

------------------------------------------------------------------------

## 2. セル内分散を保持するためのキー追加

1.  **標準偏差（SD）や標準誤差（SE）の追加**
    -   各セルで計算したSDやSEを平均値とともにマージ用キーに含める。
    -   モデル上では、平均値とSD（またはSE）を別々の説明変数として投入し、ばらつきの効果を直接評価できる。
2.  **分位数（Q1, Q3）やIQRの追加**
    -   セル内の第一／第三四分位点をマージし、消費分布の歪度や裾野の広がりをモデル化。
3.  **ダミー化によるセル識別子の導入**
    -   地域×年×所得層ごとにIDを振り、マージ先データでもセル識別子を用いた固定効果（あるいはランダム効果）モデルを構築。

------------------------------------------------------------------------

## 3. モデル構築上の具体的アプローチ

**階層モデル（混合効果モデル）**

-   水準1（世帯）、水準2（地域×年×所得層セル）という二段階構造を明示。
-   平均値はセルレベルの固定効果、SDやSEはランダム効果の分散パラメータとして推定。
-   例：

``` r
lmer(consumption ~ cell_mean + (1 | cell_id), data = merged_data)
```

ここで `(1 | cell_id)` がセル内ばらつきを取り込む構造。

**重み付けや不確実性の反映**

-   平均推定のSEを加重の逆数として扱い、**誤差分散の異質性（heteroskedasticity）**を調整。
-   例：

``` r
lm(outcome ~ cell_mean, data = merged_data, weights = 1 / cell_SE^2)
```

**シミュレーションによる不確実性の伝播**

-   各セルの平均とSDから世帯ごとのデータをモンテカルロシミュレーションで複数生成。
-   シミュレーション結果を用いた**シンプルマルチプレイマル（Multiple Imputation）**的手法でモデル推定。

------------------------------------------------------------------------

## 4. 実践手順

1.  元データで各セルの**平均・SD・SE・四分位数**を再計算。
2.  マージ用テーブルに平均とともにSD（またはSE, Q1, Q3）を追加。
3.  マージ先データで、セル識別子を固定効果／ランダム効果や重み付け、シミュレーション手法に応じて投入。
4.  比較モデル（平均のみ vs. 分散情報含む）を推定し、AIC/BICや予測性能、信頼区間幅の変化を検証。

------------------------------------------------------------------------

**まとめ** 単純マージによる平均値だけでは、世帯間のばらつき情報が失われ、モデルの説明力と解釈力が低下します。各セルの**SD/SEや分位数**を一緒にマージし、**階層モデル・重み付け・シミュレーション**などを活用して不確実性を適切に反映することで、より頑健な分析が可能となります。
